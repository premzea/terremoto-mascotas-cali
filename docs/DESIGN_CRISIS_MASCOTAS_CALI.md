## 1. Problem Statement & Crisis Context
Cinco días después de un sismo de gran magnitud en Cali, cientos de perros y gatos permanecen separados de sus familias. La infraestructura urbana y de telecomunicaciones está afectada, y las redes de rescate animal operan al límite. El sistema de información está fragmentado y es vulnerable a estafas de extorsión.

---

## 2. Decisiones de Ingeniería Críticas (Outside Voice & SRE Audit)

1. **Arquitectura Simplificada (Next.js Fullstack + Supabase):**
   - Eliminamos el microservicio de FastAPI. Stack unificado: Next.js (App Router) + Supabase.
   - **Mitigación de Pool de Conexiones (SRE Fix):** Uso explícito de **Supavisor** (el nuevo estándar de Supabase, puerto 5432, Transaction Mode), ya que PgBouncer fue deprecado.

2. **Desacoplamiento de Ingesta e IA (SLA Ingesta < 300ms):**
   - El endpoint persiste datos en $<300\text{ ms}$.
   - **SRE Fix (Prevención de Asesinato de Contexto Vercel):** La IA asíncrona de Gemini se envuelve obligatoriamente en `waitUntil()` (función nativa de Vercel) para evitar que la lambda sea destruida al retornar el HTTP 201.
   - **DLQ y Reintentos (SRE Fix):** Se configura un worker/cron en Supabase (`pg_cron`) para re-procesar los reportes con `ai_status = 'PENDING'` que hayan sufrido Timeouts o 429 de la API de Gemini.

3. **Manejo Espacial y Offline (Resiliencia Extrema):**
   - **Trampa GPS de WhatsApp:** Uso de catálogo barrial (`coords_by_barrio.json`) con `COALESCE(location, barrio_centroid)` para compensar la falta de metadatos EXIF.
   - **Resiliencia Offline iOS/PWA (SRE Fix):** Debido a que iOS Safari congela pestañas offline, NO confiaremos ciegamente en sincronización en segundo plano. Se implementará un **"Unsynced Data Badge"** rojo, persistente en la UI, que obliga al usuario a tocar para sincronizar manualmente su `IndexedDB` al recuperar la red.
   - **Memoria de Teléfonos (OOM):** Uso intensivo de Web Workers con `browser-image-compression` para comprimir imágenes de 12 MP en el frontend (reduciendo carga en red y previniendo que se consuman quotas de Storage).

4. **Escudo Anti-Extorsión (SRE Fix):**
   - **Evitar WhatsApp Directo Público:** Es imposible ocultar un número de teléfono en un enlace `wa.me`. Los estafadores automatizados usarían bots para extraer los números.
   - **Solución Real:** Todo contacto de coincidencias se enrutará a un número de **WhatsApp de Triaje Centralizado de Voluntarios** con el ID del caso, quienes se encargarán de mediar con el dueño verificando fotos privadas antes de triangular la comunicación, garantizando cero exposición de números públicos.

## 3. Data Schema (Supabase PostgreSQL)

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "postgis";
CREATE EXTENSION IF NOT EXISTS "vector";
CREATE EXTENSION IF NOT EXISTS "pg_cron";

-- Tabla principal de mascotas
CREATE TABLE pets (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    report_type VARCHAR(20) NOT NULL CHECK (report_type IN ('LOST', 'FOUND', 'SHELTERED')),
    species VARCHAR(20) NOT NULL CHECK (species IN ('DOG', 'CAT', 'OTHER')),
    primary_color VARCHAR(50) NOT NULL,
    secondary_color VARCHAR(50),
    neighborhood VARCHAR(100) NOT NULL,
    location GEOGRAPHY(Point, 4326),
    photo_url TEXT NOT NULL,
    embedding vector(768),
    raw_ai_features JSONB DEFAULT '{}',
    -- Contactos ocultos
    contact_name VARCHAR(100) NOT NULL,
    contact_phone_encrypted TEXT NOT NULL,
    status VARCHAR(30) DEFAULT 'ACTIVE',
    ai_status VARCHAR(30) DEFAULT 'PENDING' CHECK (ai_status IN ('PENDING', 'PROCESSED', 'FAILED')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Índices de alto rendimiento
CREATE INDEX idx_pets_filter ON pets (species, report_type, status);
CREATE INDEX idx_pets_neighborhood ON pets (neighborhood);
CREATE INDEX idx_pets_location ON pets USING GIST (location);
CREATE INDEX idx_pets_ai_pending ON pets (ai_status) WHERE ai_status = 'PENDING';
```

## 4. Failure Modes Registry & Error Rescue Map

| Codepath / Riesgo | Causa Principal | Manejo de Excepción / Rescue (SRE Fixes) |
| :--- | :--- | :--- |
| **Silent AI Failure** | Vercel mata el Server Action asíncrono al enviar el Response. | Usar `waitUntil()` de `@vercel/functions` para proteger el ciclo de vida del LLM. |
| **Gemini Quota 429** | Spike masivo de fotos en 1 hora agota tokens de Gemini. | Supabase `pg_cron` actúa como Dead Letter Queue reintentando fallos en batch cada 5 min. |
| **Offline Data Loss iOS**| iOS Safari suspende Service Workers y Background Syncs. | Badge Persistente Rojo en UI ("1 foto por subir") + botón de Sync manual. |
| **Supabase DB Crashing**| PgBouncer obsoleto causa fallos de cadena de conexión. | Migrar a Supavisor (Port 5432 / Transaction Mode). |
| **Scraper Extortion** | Extracción masiva de números telefónicos de víctimas. | Ocultar API de contacto en Triaje Central; jamás exponer un `wa.me/num_victima`. |

## 7. Design System & UI UX Specifications (plan-design-review)

**Decisiones de Diseño de Crisis (Basadas en Revisión de 7 Fases):**

1. **Arquitectura de Información (Pantalla Dividida 50/50):** 
   El usuario verá un layout 50/50 de impacto inmediato. Arriba "¿Perdiste a tu mascota?" y Abajo "¿Encontraste una mascota?". Elimina la necesidad de entender la navegación. (Pass 1).
2. **Jerarquía Visual ("Edge-to-Edge Cards"):** 
   El feed fotográfico irá de borde a borde para maximizar tamaño de imágenes (mín 150px altura). (Pass 2).
3. **Manejo de Estados de Carga (Carga Optimista):**
   Las fotos se guardan en IndexedDB y el usuario regresa inmediatamente al feed. Un "Badge Rojo" notifica subidas pendientes, permitiendo multitarea sin que Safari mate el proceso asíncrono. (Pass 2).
4. **Viaje del Usuario (Tono "Utilidad de Emergencia"):**
   El copy de la aplicación será extremadamente directo. Cero mensajes emocionales de relleno. Asume estrés extremo y batería baja. (Pass 3).
5. **Empty States Activos:**
   Si no hay mascotas cercanas, no se mostrará "Sin resultados". Botón masivo: **"Ampliar radio a toda la ciudad"**. (Pass 4).
6. **Accesibilidad y Consumo (Dark Mode Exclusivo):**
   Diseño anclado en Dark Mode obligatorio para ahorrar batería en pantallas OLED y reducir el brillo nocturno, vital en un contexto de desastre. Touch targets de mínimo 48px. (Pass 6).
7. **Resolución Anti-Extorsión (Gate Fotográfico Local):**
   Para desbloquear el WhatsApp del Triaje de un animal reportado como perdido, el usuario (rescatista) está forzado por la UI a tomar/subir una foto del animal que encontró. El sistema cruza este bloqueo antes de mostrar contactos para repeler bots raspadores. (Pass 7).
